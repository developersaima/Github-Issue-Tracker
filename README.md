1️⃣ Difference between var, let, const

var → function scoped, can be re-declared and updated, not recommended in modern JS
let → block scoped, cannot be re-declared in same scope but can be updated
const → block scoped, cannot be re-declared or re-assigned (used for fixed values)


2️⃣ Spread operator (...)

Used to expand elements of an array or object
Helps to copy, merge, or pass values easily
Example: combining arrays or cloning objects


3️⃣ map(), filter(), forEach()

map() → loops through array and returns a new array after modifying each element
filter() → returns a new array with elements that match a condition
forEach() → loops through array but does not return anything (used for side effects)


4️⃣ Arrow function

A shorter way to write functions using =>
Does not have its own this (inherits from parent scope)
Makes code cleaner and more readable


5️⃣ Template literals

Strings written using backticks (`) instead of quotes
Allows embedding variables using ${}
Supports multi-line strings easily
